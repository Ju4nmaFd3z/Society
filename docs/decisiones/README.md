# Decisiones

Registro de las decisiones importantes del proyecto: qué se decidió, por qué y qué se descartó.

## Cómo se añade una decisión

1. Copiar [`plantilla.md`](plantilla.md).
2. Nombrarla con el siguiente número y un título corto: `0003-titulo-corto.md`.
3. Rellenarla y añadirla a la lista de abajo.

Si una decisión se sustituye por otra, no se borra: se cambia su estado y se enlaza a la nueva.
