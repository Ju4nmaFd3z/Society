# Repositorios

El proyecto tiene un repositorio por tecnología, más uno general.

## Mapa

| Repositorio | Tecnología | Contenido |
| --- | --- | --- |
| [Society](https://github.com/Ju4nmaFd3z/Society) | Documentación | Producto, diseño, arquitectura, marca y decisiones |
| [Society-Kotlin](https://github.com/Ju4nmaFd3z/Society-Kotlin) | Kotlin | App móvil Android, con Jetpack Compose |
| [Society-TypeScript](https://github.com/Ju4nmaFd3z/Society-TypeScript) | TypeScript | Alcance por definir |

## Reglas

- La documentación común (producto, diseño, marca y decisiones) vive solo en el repositorio general.
- Cada repositorio de tecnología documenta su propio código y enlaza al general para lo común.
- Todos los repositorios siguen la misma [guía de estilo](../guia-de-estilo.md) y el mismo flujo de trabajo.
- Si se incorpora una tecnología nueva, se crea su repositorio, se añade una fila a esta tabla y se enlaza desde el README del repositorio general.
