# 09. Contenido creado

Resultado de la creación de contenido.

## Objetivo

Mostrar el contenido creado, recoger la opinión del usuario y permitir subirlo.

## Diseño

- Flujo: [Flujo de navegación](../flujo-de-navegacion/README.md).
- Figma: pestaña v3 · Cristal líquido. Ver [Diseño](../README.md).

## Contenido

El diseño solo tiene la cabecera «Crear contenido». El contenido previsto es:

- Demostración del contenido creado, con feedback y posibilidad de recrear las piezas que no hayan gustado.
- Propuesta de hashtags, pie del post y hora de subida, editable.
- Botón para subir el contenido directamente.

## Estados

Por definir. Si la pantalla muestra datos, incluirá los cuatro estados obligatorios: cargando, vacío, error y con datos.
