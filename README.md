# Society

SaaS para gestionar redes sociales, marketing y publicidad de negocios de hostelería: restaurantes, bares y cafés.

Proyecto de fin de grado (TFG) de 2º de Desarrollo de Aplicaciones Multiplataforma, curso 2026/27.

## Autores

- Juanma Fernández
- Víctor Pagola
